# 插件与组件

首版采用编译时插件。模块由仓库内可信代码组成，随应用一起构建与发布。管理员可启用模块、创建多个组件实例、选择数据源、调整顺序与展示样式。

当前边界如下：

| 文件/目录 | 职责 |
| --- | --- |
| `src/shared/catalog.ts` | 模块清单、API 版本、组件类型、数据源类型和能力要求 |
| `src/shared/types.ts` | 组件实例、应用状态、主机指标、连接展示数据等共享类型 |
| `src/web/plugins/types.ts` | 前端插件的 `id` 与 `render` 接口 |
| `src/web/plugins/registry.tsx` | 显式导入和注册已安装的前端插件，按模块 ID 分发渲染 |
| `src/web/plugins/hosts.tsx` | 基础节点、GPU 节点与汇总组件 |
| `src/web/plugins/newapi.tsx` | NewAPI 额度组件 |
| `src/server/plugin.ts` | 后端 `ServerPluginContext`，提供路由、存储、时钟与配置访问 |
| `src/plugins/registry.ts` | 注册后端插件，组合实时快照与关闭生命周期 |
| `src/plugins/hosts/` | 节点路由、采集校验、实时状态与历史聚合 |
| `src/plugins/newapi/server.ts` | NewAPI 连接路由、刷新状态与生命周期 |
| `src/plugins/newapi/connector.ts` | NewAPI 固定只读请求、响应归一化及连接输入检查 |
| `src/server` | 会话、配置校验、存储、实时流与应用生命周期 |

共享清单的 `apiVersion` 当前为 `1`，用于描述这个仓库内的接口版本。它尚未提供独立插件包协商、迁移框架或跨版本兼容加载。

## 增加一个组件类型

1. 在已有模块的清单中增加稳定的 `type`、名称和说明，选择 `source: 'node' | 'connection' | 'none'`。需要 GPU 时添加 `capability: 'gpu'`。
2. 在该模块的前端 `render` 中处理新类型。渲染通过 `WidgetRenderProps` 获取组件实例、实时状态与查看历史的回调。
3. 复用现有指标和连接数据时直接读取共享状态；若需新数据结构，同时更新共享类型、服务端校验与数据提供逻辑。
4. 为新行为增加适当测试，运行类型检查、测试与构建。

## 增加一个模块

在 `src/shared/catalog.ts` 中增加唯一模块 ID、元数据与组件定义；在 `src/web/plugins/registry.tsx` 中显式注册前端实现。清单和注册表都需要更新，仅添加目录不会自动安装模块。

若需要后端，在 `src/plugins/<id>/server.ts` 中导出注册函数，接收 `ServerPluginContext`；通过 `context.app` 注册 `/api/plugins/<id>/...` 路由，并在 `src/plugins/registry.ts` 中显式调用注册函数。核心统一为 `/api/` 路由检查会话与写操作的 CSRF；不要自行添加免认证路径。只有内置主机采集入口使用独立节点令牌。

注册函数返回数据快照、调度入口和关闭函数；注册表组合快照与关闭流程。需要定时任务时，在 `src/server/app.ts` 中显式接入调度，关闭时等待未完成的任务。当前共享状态仍定义了主机与 NewAPI 的具体数据结构，新增数据源种类需要扩展共享类型及校验，尚无独立插件包的自动装载与通用数据总线。

组件可以拥有自己的 CSS 或动画，使用模块前缀避免样式冲突；必须尊重 `.no-animations` 和 `prefers-reduced-motion`。颜色优先读取 `--accent` 等主题变量。插件缺失时显示简短占位，单个数据源失效不影响其他组件。

新增连接器只能接受它需要的配置；固定服务端请求路径、限制超时和响应大小，并将凭据留在服务端。浏览器状态与错误消息中不能包含可用令牌。缺失值使用 `null`，真实零值使用 `0`，离线时不把旧值继续展示为实时测量。

## 禁用、删除与代码信任

禁用模块会隐藏对应组件；NewAPI 禁用时停止发起新的定时刷新，已发出的请求可能完成。模块配置与组件实例仍可保留，重新启用后继续使用。删除节点或连接时，核心会删除引用该数据源的相应组件。

插件运行在应用自身的权限范围内，没有隔离沙箱。安装新代码意味着信任该代码及其依赖，必须先审核再构建。当前不支持从界面上传或下载可执行插件、不支持插件市场与运行时热加载。
